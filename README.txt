ARK DUMP PWA

Esta é a versão web instalável no iPhone (Adicionar à Tela de Início).

IMPORTANTE:
Safari/iOS não expõe a Web NFC para páginas/PWAs, então esta versão não consegue iniciar a leitura NFC nativa do iPhone. Ela funciona para análise/importação de dumps, visualização das páginas, PWD/PACK e texto/NDEF disponível nos arquivos.

Como usar:
1. Hospede esta pasta em HTTPS (GitHub Pages, Cloudflare Pages, Netlify, etc.).
2. Abra o endereço no Safari do iPhone.
3. Compartilhar -> Adicionar à Tela de Início.
4. Importe um dump .bin/.hex/.txt.

O código não depende de backend.
